# Caltech — Student Life and Opportunities

This directory records current student-life, extracurricular, research, and development opportunities published by Caltech. The emphasis is on opportunities that are relevant to an undergraduate interested in mathematics, computer science, physics, and quantum computing.

The current official club directory lists approved clubs for 2025–2026, while the 2026–2027 registration process is currently open. Information is therefore separated by academic-year status where necessary.
