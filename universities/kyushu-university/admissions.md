# 九州大学 — 入試・admissions

`universities/kyushu-university/admissions.md`

> 九州大学の学部入試・大学院入試の制度をまとめたファイルです。日本の国立大学の入試制度は多様な選抜方式が並行して実施されるため、Caltechの`admissions.md`とは構成がやや異なります。募集人員・日程は年度により変動するため、**必ず九州大学公式サイトの最新の学生募集要項で確認してください。**

---

## 1. 学部入試 — 選抜方式の全体像

九州大学の学部入試は、以下の複数の選抜方式を並行して実施している(令和8年度入試の例)。

| 選抜方式 | 概要 |
|---|---|
| **一般選抜** | 大学入学共通テスト+個別学力試験による標準的な選抜方式。最も募集人員が多い。 |
| **総合型選抜Ⅰ** | 学部ごとに実施される総合型選抜(旧AO入試に相当)。学部により内容が異なる(例:共創学部、教育学部など)。 |
| **総合型選抜Ⅱ** | 総合型選抜のうち、Ⅰとは別枠で実施される選抜区分。 |
| **学校推薦型選抜** | 高等学校からの推薦に基づく選抜方式(旧推薦入試に相当)。 |
| **帰国生徒選抜** | 海外の教育機関等で一定期間就学した帰国生徒を対象とする選抜。 |
| **私費外国人留学生入試(4月・10月)** | 私費で就学する外国人留学生を対象とする入試。4月入学・10月入学の両方に対応する学部がある。 |
| **国際型入試(10月入学)** | 共創学部が英語で実施する10月入学向けの国際型入試。 |
| **国際コース入試(10月入学)** | 農学部が英語で実施する10月入学向けの入試。 |
| **国際入試** | 教育学部が実施する国際入試。 |
| **3年次編入学試験** | 他大学等からの3年次編入を対象とする試験。 |

⚠️ 各選抜方式の詳細な募集人員・実施学部は年度により変わるため、最新の「大学案内・入学者選抜概要・募集要項」ページで確認する必要があります。

## 2. 一般選抜

- **試験構成:** 大学入学共通テスト + 各学部が指定する個別学力試験(前期日程が中心。学部・学科により異なる)。
- **出願方法:** インターネット出願システムを利用。
- **募集要項の公開:** 前年度秋〜冬にかけて、当該年度の学生募集要項が公式サイトで公開される(例:令和7年度分は前年度中に公開)。

## 3. 総合型選抜(Ⅰ・Ⅱ)

- 学部ごとに実施内容が異なり、書類審査・面接・小論文・プレゼンテーションなどを組み合わせるのが一般的(旧AO入試の流れを引く制度)。
- 例:共創学部、教育学部などが総合型選抜Ⅰの対象学部として公式サイトに個別ページを持つ。
- ⚠️ 学部ごとの詳細な評価基準・提出書類は、各学部の個別ページ(例:`kyosogaku`、`education`等のURLパス)で確認が必要。

## 4. 学校推薦型選抜

- 出身高等学校長の推薦に基づく選抜。学部ごとに推薦要件(evaluation基準、学業成績の目安等)が異なる。
- 早稲田塾など予備校系の解説サイトでも取り上げられるほど、九州大学の総合型・学校推薦型選抜は一定の知名度を持つ(ただし詳細は必ず公式要項で確認すること)。

## 5. 国際的な入試制度(留学生向け)

### 私費外国人留学生入試
- 私費で九州大学に進学する外国人留学生を対象とする入試制度。
- **4月入学**と**10月入学**の両方の枠がある(10月入学は工学部が英語で実施)。

### 国際型入試(10月入学)
- **共創学部**が英語で実施。10月入学に対応。

### 国際コース入試(10月入学)
- **農学部**が英語で実施。10月入学に対応。

### 国際入試
- **教育学部**が実施する、国際的な背景を持つ受験者を対象とした入試制度。

⚠️ これらの英語基準の入試制度(国際型入試・国際コース入試・私費外国人留学生入試)は、詳細な出願資格・必要試験(TOEFL/IELTS等)・出願時期が学部ごとに異なるため、各学部の英語版公式サイトで直接確認することが強く推奨されます。

## 6. 3年次編入学試験

- 他大学等の学部を卒業(または卒業予定)の者などを対象に、3年次への編入学試験を実施。
- 対象学部・募集人員は限定的であり、学部ごとに募集の有無が異なる。

## 7. 特別な配慮・受験資格に関する制度

- **障害等のある入学志願者への合理的配慮**:出願前の事前相談制度あり。
- **高校卒業(程度)を満たさない者の受験資格について**:高等学校卒業に準ずる資格の取り扱いに関する規定が公式サイトに掲載されている。

## 8. 出願手続き

- **出願方法:** インターネット出願システムを通じて出願(紙媒体との併用については要項で確認)。
- **募集人員:** 学部・学科・選抜区分ごとに「令和8年度学部学生募集人員」等のPDFで公開される。

## 9. 学費・奨学金・免除制度(入学者向け)

| 制度 | 概要 |
|---|---|
| 学生納付金 | 入学料・授業料等(国立大学の標準額に準拠するのが通例。九州大学独自の設定がある場合は要確認) |
| 入学料免除(徴収猶予)・授業料免除 | 経済的事情等による免除・徴収猶予制度 |
| 高等教育の修学支援新制度による授業料等減免 | 国の修学支援新制度に基づく減免(多子世帯無償化を含む) |
| 被災学生への入学料免除・徴収猶予、授業料免除 | 災害被災者向けの特例制度(令和6年能登半島地震などへの対応も含む) |
| 奨学金 | 日本学生支援機構(JASSO)奨学金等、複数の奨学金制度への案内あり |

⚠️ 具体的な学費金額(標準額との差異含む)は、公式サイトの「学生納付金」ページで最新の数値を確認してください。

## 10. 大学院入試

- 大学院(学府)入試の募集要項は、学府ごとに個別に公開される。
- 出願資格・選抜方法(書類審査・筆記試験・口頭試問等)は学府・専攻により大きく異なる。
- ⚠️ 20学府すべての個別入試要件を網羅するには、学府ごとの追加調査が必要(今回は概要レベルの言及のみ)。
