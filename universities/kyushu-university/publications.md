# 九州大学 — 出版物・学術情報リポジトリ

`universities/kyushu-university/publications.md`

> 九州大学の学術情報基盤は、**九州大学学術情報リポジトリ(QIR)**を中核とし、2016年策定のオープンアクセス方針、教員活動報告システム(Q-RADeRS)との連携、そして近年のオープンデータ推進(研究データ管理)まで、比較的よく整備された体系を持つ。附属図書館が一貫して運営している。

---

## 1. 九州大学学術情報リポジトリ(QIR)

- **正式名称:** 九州大学学術情報リポジトリ(Kyushu University Institutional Repository、略称 **QIR**)。
- **運営:** 九州大学附属図書館。
- **収録内容:** 学術雑誌掲載論文、テクニカルペーパー、紀要論文、学位論文など、**九州大学所属の教員・大学院生の著作物**(名誉教授や以前所属していた者の著作物を含む)。
- **公開方針:** インターネットを通じて学内外に**原則無償で配布**。
- **システム基盤:** 図書館業務システム「**E-CatsLibrary**」を用いて構築されており、メタデータの流通や学内システムとの連携機能を強化している。
- **登録可能な範囲:** 紀要論文・博士論文はもちろん、学術雑誌論文についても**著者最終稿(査読済みの受理版)**を公開してオープンアクセス化できる。研究データや論文の根拠データの公開も可能。

## 2. 沿革

| 年 | 出来事 |
|---|---|
| (QIR運用開始、具体的年不明) | 九州大学学術情報リポジトリ(QIR)の運用開始 |
| 2013年12月 | 「九大コレクション」に統合(トップ画面の統合は2018年〜) |
| **2016年1月19日** | **九州大学オープンアクセス方針**を採択(公的研究資金を用いた研究成果のQIRでの公開を策定) |
| 2016年12月2日 | オープンアクセス方針の実施要領を決定 |
| **2017年1月1日** | オープンアクセス方針の**運用開始**。同日以降に出版された研究成果をQIRに登録することが教員に求められるようになった |
| 2018年1月9日 | 九州大学教員活動進捗・報告システム「**Q-RADeRS(キューレーダーズ)**」との連携機能運用開始(業績入力時にQIR登録依頼が可能に) |
| 2021年3月 | 中村哲著述アーカイブの公開(「中村哲先生の志を次の世代に継承する九大プロジェクト」の一環) |
| 近年 | 「リポジトリ登録インセンティブ」の導入、「リポジトリ登録支援システム」の開発など、機能・制度両面でオープンアクセス推進を加速 |
| 2025年 | QIR公開20周年 |

## 3. オープンアクセス方針の詳細

- 2016年1月19日採択、**2017年1月1日運用開始**。
- **対象:** 公的研究資金を用いた研究成果。
- 教員は、公開されている登録手順(マニュアル)に従い、2017年1月1日以降に出版した研究成果をQIRに登録することが求められる。
- 登録負担軽減のため、大学評価情報システム(九州大学研究者情報)からの研究成果登録も可能になっている。
- **政府方針との連携:** 内閣府 科学技術・イノベーション推進事務局による「学術論文等の即時オープンアクセスの実現に向けた基本方針」(2024年10月更新のFAQを含む)を踏まえ、大学レベルでの対応も進められている。

## 4. researchmap連携・登録の簡易化

- **researchmap連携:** researchmapに登録した論文情報を用いて、簡単にQIRへリポジトリ登録できる機能がある。まだオープンアクセスになっていない論文を選択し、本文ファイルをアップロードして公開する運用。
- 2025年10月には登録申請フォームがリニューアルされ、研究成果をより簡単に登録できるようになった。

## 5. 研究データ管理

- QIRでは、**研究データや論文の根拠データの公開**も可能。
- **九州大学データ駆動イノベーション推進本部 研究データ管理支援部門**が、研究データ管理の支援を担当。
- 政府の即時オープンアクセス方針との連動が進められている。

## 6. 学位論文(博士論文)の公開

- QIRは学位論文(博士論文)の公開機能を持つ。
- ⚠️ 学位規則(`graduate_research.md`参照)との具体的な連動プロセス(博士論文提出義務とQIR登録義務の関係)の詳細は、今回の調査では十分に確認できていない。

## 7. 図書館・特別アーカイブ

- **中村哲著述アーカイブ**:アフガニスタン・パキスタンでの人道支援活動で知られる医師・九州大学出身の中村哲氏の著述を後世に伝えるためのアーカイブプロジェクト。
- 九州大学附属図書館は、中央図書館のほか各キャンパスに分館を持つ(詳細は`resources.md`で扱う予定)。
